Silicon Miner

Weekend project · 2026

An educational Bitcoin SHA-256d miner for Apple Silicon (M1 Pro / ARM64). The hash path is pure ARM64 assembly, using the crypto extensions. C is only the harness, Stratum, and the rest around it.

The point was learning and correctness. It connects to testnet Stratum only.

On a MacBook Pro (MacBookPro18,3), the early one-thread midstate harness ran at about 20.7 MH/s. With eight threads and dual-job, an offline soak later measured about 125 MH/s, and a live testnet run about 100 MH/s.

I wrote none of the code. I worked it out with Grok, by voice in the Tesla and with Grok Bot.
